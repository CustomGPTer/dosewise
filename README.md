# Dosewise

Dosewise is a free, private medicine reminder for Android: alarms that really ring, about 20,000 UK medicines built in, label scanning, streaks, supplies and repeat prescriptions, health readings with NHS ranges, reports and an emergency card. No adverts, no account, no internet.
